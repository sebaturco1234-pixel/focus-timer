# Focus Timer

Un temporizador Pomodoro simple con modo de enfoque, pausas y lista de tareas diarias.

## Uso

Abrí `focus-timer/index.html` en tu navegador. No requiere instalación.

## Modos

- **Enfoque 25** — sesión de trabajo de 25 minutos
- **Pausa 5** — descanso corto de 5 minutos
- **Pausa 15** — descanso largo de 15 minutos

Las sesiones completadas se guardan automáticamente en `localStorage`.
